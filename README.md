# Audio Player

A lightweight desktop audio player for Windows with a red/black theme

## Download

Grab the latest installer from the Releases page. Run it, pick where to install, done.

## What it does

- Drag and drop audio files or use the file picker
- Playlists — create, rename, pin, delete
- Drag tracks between playlists
- Rename tracks
- Shuffle and repeat (off / all / one)
- Remembers where you left off — reopen the app and it picks up from the exact second
- Media key support (play/pause/skip from keyboard)
- Custom UI with elastic volume slider and animated effects

## Audio formats

MP3, WAV, OGG, FLAC, M4A, AAC, WMA, OPUS, WEBM - basically all audio file types

## Where are my files stored?

Audio files get copied to:
%AppData%\audio-player-adxmo\audio_files\

Playlists and playback state are saved in localStorage.
